# Content Plan - July 2026

这份计划服务于 `AI Project Ideas` 的 GitHub 增长，不追求“大而全”，重点是把仓库里的旗舰 idea 转成可传播、可反馈、可继续补深的中文内容。

## 本月目标

- 把 `AI GitHub Profile Maker` 打造成第一个最有辨识度的 flagship idea
- 把 `AI README Generator` 作为第二个 GitHub 场景工具补上
- 每周至少发布 1 条中文内容
- 每条内容都能回流到仓库中的具体页面，而不是只回流到仓库首页

## 内容主线

### 1. GitHub 个人主页增长

围绕 `AI GitHub Profile Maker` 展开。

适合讲的点：

- 为什么很多开发者 GitHub 有内容但没有转化
- 什么样的 Profile README 更容易让人继续点仓库
- Pinned 仓库应该怎么选
- 为什么“真实、持续更新”比“堆大词”更重要

### 2. GitHub 仓库首页转化

围绕 `AI README Generator` 展开。

适合讲的点：

- README 为什么直接影响 Star 和停留时间
- 新访客点进项目后最先看什么
- 一个差 README 通常缺什么
- 如何把 README 从“说明书”写成“转化页”

### 3. 开发者工具型 AI 项目

围绕 `Repo Reader Agent`、`AI Code Reviewer`、`AI Commit Assistant`、`AI OSS Issue Triage Copilot` 展开。

适合讲的点：

- 哪类 AI 项目更适合开发者开源
- 为什么开发者工具类项目更容易在 GitHub 传播
- 如何从 idea 走到第一个真实 MVP
- 为什么 Git 工作流里的小工具更容易先做成可用产品

## 每周安排

## Week 1

- 主题：`AI GitHub Profile Maker`
- 目标：把它立成第一个 flagship idea
- 建议标题：
  - `我做了一个 AI 工具：输入 GitHub 用户名，自动生成个人主页和涨粉计划`
  - `为什么很多开发者的 GitHub 看起来不差，但没人愿意继续点`

## Week 2

- 主题：`AI README Generator`
- 目标：承接 GitHub 场景，补“仓库首页转化”
- 建议标题：
  - `很多项目拿不到 Star，不是因为没价值，而是 README 没讲明白`
  - `我在补一个 AI README Generator：想解决 GitHub 首页转化问题`

## Week 3

- 主题：`Repo Reader Agent` / `AI Code Reviewer` / `AI Commit Assistant`
- 目标：把方向从“包装 GitHub”扩展到“读懂 GitHub / 维护 GitHub”
- 建议标题：
  - `如果让 AI 帮你先读懂一个仓库，再决定要不要深入，会怎样？`
  - `AI Code Reviewer 值不值得做成开源项目？`
  - `一个 AI Commit Assistant，能不能把 Git 历史质量拉起来？`

## Week 4

- 主题：月度总结
- 目标：把本月新增内容重新打包成仓库更新总结
- 建议标题：
  - `这个月我把 AI Project Ideas 往前推了两步：不是多 10 个点子，而是多 2 个更能开干的方向`
  - `我现在更想做“可以直接开干”的 AI 项目库，而不是点子收藏夹`

## 内容模板

每条内容尽量包含：

1. 一个具体问题
2. 为什么这个问题值得做
3. 我这次补了什么
4. 后面准备怎么推进
5. 仓库链接落到具体 idea 页面

## 分发建议

- GitHub：体现在 `README`、`weekly updates`、具体 idea 页面
- 中文平台：公众号 / 小红书 / 即刻 / Twitter(X) 中文内容
- 长文：优先写“为什么值得做”和“怎么开始做”
- 短内容：优先截取 before / after、错误示例、结构对比

## 追踪指标

- 仓库首页点击是否更集中到 flagship idea
- 哪个 idea 页面更容易被继续展开
- 哪类内容更容易引来开发者互动
- 内容发布后 3 到 7 天内是否带来 Star / Follow / 收藏 / Issue 反馈

## 当前建议

- 先把 `AI GitHub Profile Maker` 和 `AI README Generator` 视为同一条 GitHub 增长工具线
- 后续可以把它们和 `AI Commit Assistant` 合并包装成一个更完整的 developer growth tool suite
